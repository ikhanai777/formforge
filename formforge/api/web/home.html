FormForge

Describe the part. Get a model that prints.

FormForge turns a plain-English description into a print-ready STL or 3MF by driving a parametric CAD kernel — not a mesh generator. Every model comes back with the source that built it, the parameters it used, and a design-for-manufacture report measuring wall thickness, overhangs and clearances against your printer's profile.

What you get

Parametric, not generated mesh

A build123d script produces the geometry, so dimensions are real dimensions and a change is a parameter change rather than a re-roll.

Checked before you print

Each model is measured against a printer profile. Thin walls and unsupported overhangs come back as warnings, not surprises on the bed.

Sliders, with the model moving

The studio draws every parameter of a template as a slider over a live 3D view. Move one, watch it rebuild, then send those exact numbers to the kernel for the real, validated STL.

Six generators, not one prompt box

Mushrooms, vases, sculptural vases, candle holders, watchtowers and cup holders — each with its own species or styles, seeded so a population rebuilds exactly.

Reproducible

The source and the parameters ship with every model, so anyone can rebuild it exactly — including you, later.

Credits

A new account starts with free credits. A credit is charged when a build finishes and passes validation — a failed build costs nothing. Your balance and full credit history are on the account page.

FormForge runs locally: SQLite, files on disk, offline billing, an email outbox in a folder. No payment is taken and nothing leaves this machine.
